# Motion principles and eligibility

## Rule strength

- **Requirement:** preserve correct task behavior, accessible information, user control, and truthful state. Apply an accessibility criterion with its actual conditions and exceptions.
- **Default:** begin with restrained productive motion, then adjust to task, repetition, distance, and brand. State the reason for an exception.
- **Hypothesis:** label expected comprehension, speed, confidence, or conversion benefits until evaluated.

Resolve competing advice in this order: user/project intent and task correctness; applicable accessibility needs; observed behavior and performance; contextual defaults; aesthetic preference. Honor the user's scope while making material tradeoffs explicit. Treat source-skill heuristics as design guidance rather than standards.

## Eligibility gate

For each candidate, record:

1. **Need:** what must the user notice, understand, or control?
2. **Purpose:** choose one primary job from the table below.
3. **Static alternative:** could layout, copy, contrast, or an immediate update communicate it better?
4. **Exposure:** how often is it seen, through which input, and during what task?
5. **Control:** when does feedback begin and when can the user act again?
6. **Equivalent:** how is the information/function available without spatial motion?

Choose add, keep, reduce, refine, or remove. Approve movement when the stated purpose outweighs its interruption cost. Preserve stillness when the static interface already communicates adequately.

| Purpose | Appropriate communication |
|---|---|
| Feedback | Acknowledge input locally and promptly |
| State/progress | Make status and transitions legible |
| Continuity | Preserve object identity and spatial relationships |
| Focus | Clarify the current priority or layer |
| Explanation | Demonstrate cause, transformation, and outcome |
| Reward/brand | Express character at a meaningful moment |
| Atmosphere | Support an expressive scene without competing with content |

## Context defaults

| Context | Default decision |
|---|---|
| Rapid navigation, keyboard selection, dense data | Instant or minimal feedback; preserve stable reading targets |
| Frequent controls | Brief, local acknowledgement; avoid imposing a repeated wait |
| Occasional overlay/disclosure | A short bridge that explains state or space |
| Milestone/first-use | Expression may be useful if control and information remain available |
| Landing-page demonstration | Explain the product; keep conversion UI productive |
| Gesture-driven surface | Continuous direct control followed by predictable settling |

Classify frequency from actual use or label the assumption. Treat “100 times/day” as a prompt to assess repetition, not a numerical eligibility law. Judge keyboard motion by response and obstruction, not the input device alone.

## Semantic consistency

Give equivalent actions equivalent behavior. Different meanings may use different movement. Preserve origins and identity; represent cancel/return through the established spatial relationship. Derive directional conventions from layout, hierarchy, and locale. A left/right signifier is not universal.
